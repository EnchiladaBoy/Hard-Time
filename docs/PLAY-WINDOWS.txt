HARD TIME - NATIVE WINDOWS x64

Launch "Play Hard Time.exe" or your Hard Time (Native) shortcut. Installations
made with the Python build script use "Play Hard Time.cmd" instead.
Keep this folder in a writable location.
The launcher makes a dated copy of Data in backups before every run and
records diagnostics in logs. It prevents two copies from using these saves
at once. Closing the game window saves active gameplay before exiting.

Use the arrow keys and Enter in menus. During play, Esc saves and returns to
the slot menu when a conversation permits it. P pauses by default, F11 toggles
the FPS counter, and F12 saves a screenshot to Photo Album. Read the original
Instruction Manual.txt and Survival Guide.txt for game controls.

Options > Modern Settings has three pages. Use left/right on PAGE to switch.
  Display: desktop resolution, 1080p, 1440p and 4K; windowed or borderless
  desktop; HUD size from 75% to 125%. Borderless uses the desktop resolution.
  Apply display changes and confirm within 15 seconds, or they revert.
  Controls / camera: mouse sensitivity, camera distance, pause on focus loss,
  and a WASD preset (J attack, K defend/run, L throw/grab, E pick up).
  Audio: independent music, sound effects and ambience volume. Alarm audio
  remains disabled; its original gameplay events still work.

Options > Redefine Keys remaps movement, all four actions and pause. Assigning
an occupied key swaps its two actions. Escape/Enter, Alt, F11 and F12 remain
reserved. Original controls remain the default. Controllers can be unplugged
and reconnected during play. Losing window focus pauses play by default;
press your pause key to resume after returning.

Progress, options and character photographs are in Data. Screenshots are in
Photo Album. To restore a backup, close the game, preserve the current Data
folder elsewhere, then copy the selected backups/<date> folder as Data.
Backups are retained until you remove them.

Game saves are staged before the complete Data folder is switched into place.
Data.previous retains the last committed generation. The launcher recovers
an interrupted directory switch automatically. Options use atomic writes
and .bak recovery copies; damaged settings are preserved as .corrupt.dat.
Resetting an occupied slot requires confirmation, with Cancel selected first.
NativeOptions.dat stores modern preferences separately from legacy Options.dat.

Gameplay, menus, pause and scripted dialogue render at the display's refresh
rate when performance permits. Game speed and dialogue logic stay at their
original 30 updates per second. Extra frames reuse recorded UI drawing, so
they do not advance conversations or consume gameplay randomness. Loading
feedback appears as assets load. The FPS counter reports frames and clock ticks.

If software-renderer.txt is present, this installation uses Mesa llvmpipe on
the CPU. This is useful when a modern OpenGL hardware driver is unavailable.
It does not replace any Windows driver. Reduce resolution/population in the
game's Options if needed. To switch graphics modes, run Hard-Time-Setup.exe
again, choose the existing installation folder, and select GPU driver or
Compatibility. Your saves and photos are preserved. Automatic retains an
existing installation's renderer; on a fresh installation it checks for an
OpenGL 3.3 driver and falls back to compatibility graphics when unavailable.

SETUP AND UPDATES
Hard-Time-Setup.exe includes the compiled game and support files. The installer
and Play launcher are native Rust programs for Windows 10 (1903+) / 11 x64.
Players do not need Rust, .NET, Python, Git, CMake, Visual Studio, or a separate
7-Zip installation.

Setup can download the original 2007 installer directly from MDickie's site,
or use your local installer / complete original game folder. It checks the
original installer checksum, extracts it without executing it, and installs
a separate native copy. Local-file installation works offline.

Default location: %LOCALAPPDATA%\Programs\Hard Time
Install for your own Windows account; administrator rights are not required.
For an update, select the same native installation folder. Close the game
first. If setup was interrupted, rerun setup to recover and finish updating.
If a shortcut could not be created, open Play Hard Time.exe in that folder.
To remove the portable installation, keep any wanted Data, Photo Album and
backups folders elsewhere, then delete the installation folder and shortcuts.

This is an unofficial compatibility port of Mat Dickie's original game.
The name, credits and noncommercial conditions are retained; see NOTICE.txt.
Full playthroughs and physical controller testing remain outstanding.

Known preview issue: repeated F12 screenshots can darken menu graphics on the
tested Mesa software renderer. Restart the game to restore them. Use Windows
screen capture instead of F12 until this issue is fixed. Hardware graphics
drivers have not been checked for this issue.
