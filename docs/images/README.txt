README PRESENTATION ASSETS

banner.svg is an original vector illustration for this repository. It uses
system fonts and contains no embedded game files or external resources.

The PNG images are unretouched screenshots captured during native Windows
port validation, converted losslessly from the game's BMP screenshots:

  gameplay.png           Southtown prison gameplay
  courtroom.png          Original courtroom introduction
  display-settings.png   Modern display mode and HUD settings
  keyboard-controls.png  Movement, action and pause remapping

The first two captures are from the initial Windows validation; the settings
captures show the later modern settings work. They illustrate the game and
interface, not measured performance or a promise for any graphics driver.

Original Hard Time and the game artwork depicted are Copyright (C) Mat Dickie
2007. The screenshots are documentation only. See ../../NOTICE.txt.
setup.png is rendered from the actual C# setup window with example paths.
The setup interface and its small icon are drawn from repository code.
